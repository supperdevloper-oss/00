# وصلة — أداة تنظيم النشر الآمن

واجهة عربية/دارجة خفيفة لتنظيم منشورات الصور والكتابة لصفحات Facebook، مع معاينة، حفظ مسودات، برمجة المنشورات، وقائمة واضحة بالحسابات التي تحتاج مشاركة يدوية.

## التشغيل على الاستضافة

1. حمّل محتويات المجلد `public_html/` إلى مجلد الموقع عندك (`public_html` أو `htdocs`).
2. افتح الدومين. ما كاين لا build لا قاعدة بيانات لا إعدادات معقدة.
3. النسخة الحالية كتخدم مباشرة فـ **الوضع التجريبي**، وكتحفظ المسودات والبرمجة محلياً فالمتصفح (`localStorage`).

للتجربة المحلية:

```bash
cd public_html
python3 -m http.server 4173 --bind 0.0.0.0
```

## علاش المجموعات فيها مشاركة يدوية؟

الأداة ما كتستعملش Selenium، كلمات السر، cookies، ولا أي طريقة للتحايل على Facebook. النشر الآلي مخصص للصفحات المربوطة بالطريقة الرسمية فقط. المجموعات ظاهرة كمساعدة يدوية: كتنسخ النص وكتحمّل الصورة، ومن بعد كتشارك بيدك داخل المجموعة. هاد الاختيار مقصود باش ما يوقعش خرق لقواعد المنصة.

## تفعيل النشر الحقيقي للصفحات

الواجهة جاهزة للربط، ولكن النشر الحقيقي كيحتاج Meta App رسمي خاص بصاحب الصفحات، مع OAuth وGraph API وسيرفر PHP لحفظ الرموز بشكل مشفر. ما تحطش `App Secret` ولا Page Access Token فـ `index.html` ولا فـ JavaScript.

قبل التفعيل الحقيقي، خاص:

- Meta App باسمك وRedirect URI مضبوط على الدومين.
- مراجعة/تفعيل الصلاحيات التي تطلبها Meta للحساب، مثل اختيار الصفحات والنشر فيها.
- تخزين الرموز على السيرفر فقط، مع إمكانية سحب الربط.
- مراجعة يدوية للمحتوى قبل كل إرسال، واحترام حدود المنصة والتنبيهات ديالها.

إلى بغيتي ربط live فعلاً، خاص بيانات Meta App ديالك وإعداد السيرفر أولاً؛ ما كايناش طريقة آمنة ومشروعة تخلي أي موقع ينشر فحسابات Facebook بلا هاد التفويض.
