# الجزء الثالث: دراسة السوق

## الفصل 8: لمن تبيع؟ — حدّد زبونك بالاسم

### ماذا ستتعلم

- كيف تكتب «بطاقة الزبون» في نصف صفحة.
- الفرق بين «الجميع» و«زبون واحد محدد».
- أين تجد معلومات زبونك مجاناً.

### الشرح: من لا يعرف زبونه يبيع لا أحد

«زبونا هو الشباب» ليست معلومة. الشباب في مكناس والشباب في أغادير وشباب المدارس العليا ليسوا زبوناً واحداً. بطاقة الزبون تجب 6 أسئلة:

| السؤال | مثال مُعبَّأ (افتراضي) |
| --- | --- |
| من هو؟ (جنس، تقريب عمر، وضع) | طالبة جامعية، 20–24 سنة، في سكن مشترك |
| أين يقضي وقته رقمياً؟ | إنستغرام + مجموعات واتساب زميلاتها |
| ما المشكلة التي يدفع ضدها؟ | تبغى تظاهر بنتيجة موحدة للصور وفوقت قصير |
| شحال يدفع اليوم؟ (أو بكم يحل المشكلة) | تدفع لصديقة 50 درهم أحياناً، أو لا تحل |
| أين تشتري عادة؟ (قناة) | إنستغرام + Marketplace |
| ما أكبر تحفظ عندها؟ | «علاش نخلص ونتشوفش النتيجة قبل؟» |

الإجابة الإجمالي عن السؤال الخامس تعطيك **قناتك**، والإجابة السادسة تعطيك **نص إعلانك**: ابدأ بالرد على التحفظ قبل أن يُقال.

### لماذا «الجميع» خسارة؟

- الإعلان الموجَّه لـ«الجميع» يكلفك أكثر ويصل لأقل.
- الرسالة الموجَّة لشخص واحد تُكتب مرة وتُستعمل في كل منشور.
- حين يسألك زبون: «شكون كيستعمل هاد الشي؟» — الجواب الواضح يبيع، والجواب «جميع الفئات» يقتل الصفقة.

:: مثال
- **مثال افتراضي للتوضيح**: من يبيع «أكواب سحور» في رمضان. بطاقة زبون واحدة: أم عائلة، 30–45، تجهز سفرة رمضان، تبحث عن «صينية تجمع الغسيل» لا عن كوب. بطاقة أخرى: شاب يشتري هدية لأمه. الإعلان لبطاقة 1: صورة سفرة + «اجمع طاولتك». الإعلان لبطاقة 2: تغليف هدية + «هدية رخيصة كتبان غالية». نفس المنتج، إعلانان مختلفان.
::end

### أين تجد معلومات مجاناً؟

1. **تعليقات منافسين**: اقرأ تعليقات 30 زبوناً على منشورات منافسين. دوّن ما يسألون عنه (الثمن، المقاس، التوصيل، المادة).
2. **مجموعات إنستغرام/فيسبوك**: ما الذي يكتبه الناس من غير قصد إعلاني؟
3. **5 محادثات مباشرة**: اسأل 5 أشخاص يشبهون زبونك: «كيف تعالج اليوم مشكلة X؟ واش كتخلص؟» — بلا بيع، بلا إقناع، ملاحظة فقط.

### تمرين

:: تمرين
- اكتب بطاقة زبونك الستة أسئلة كاملة في دفتر المشروع (ستجد نموذجاً في الجزء 17).
- اكتب ثمرين: «رسالة تظهر لزبون 1» و«كبريزة تحفظ زبون 1».
::end

### خطأ شائع

:: خطأ
- **«نحب يكون المنتج للجميع باش نبيع بزاف»**.
- من يخاطب الجميع لا يخاطب أحداً. حتى المنتجات «العائلية» تُباع لشخص واحد يتخذ القرار (غالباً الأب أو الأم).
- **الحل**: ابدأ بأضيق زبون ممكن في أول اختبار؛ التوسع في الزبون مرحلة لاحقة.
::end

### خلاصة الفصل

:: خلاصة
- بطاقة زبون من 6 أسئلة تسبق أي إعلان.
- التحفظ السادس = مدخل إعلانك.
- 5 محادثات ملاحظة تغنيك عن شهر تخمين.
::end

## الفصل 9: كيف تدرس المنافسين فعلاً — الدليل الكامل

### ماذا ستتعلم

- أين تبحث بالضبط عن المنافسين.
- ماذا تسجل في «جدول المنافسين» (النموذج الجاهز).
- كيف تقرأ الجدول: أين الفرصة وأين الخطر.

### الشرح: البحث ليس تصفحاً، بل تسجيلاً

**أين تبحث (بالترتيب):**

1. **Facebook Marketplace**: ابحث بكلمة منتجك بلغة محلية (مثال: «كاوط شتوي»، «ساشي توصيل»، «غسيل سيارة»).
2. **صفحات إنستغرام**: ابحث بالهاشتاغات المحلية (اسم مدينتك + المنتج).
3. **إعلانات فيسبوك النشطة**: من صفحة إعلانات Meta ابحث عن إعلانات تعمل الآن لمنتجات مشابهة (هذا أقوى دليل أن هناك من يدفع ويبيع).
4. **السوق الفعلي**: سوق أسبوعي أو درب عمر أو محلات — للأسعار والعبوات.
5. **مواقع مقارنة الأسعار إن وُجدت** لمنتجات مثل الأجهزة الصغيرة.

**ماذا تسجل لكل منافس (7 أسطر فقط):**

| # | المنافس (رابط/اسم) | الثمن | التوصيل | طريقة الدفع | قوة (جملة) | ضعف (من تعليقات الزبائن) | حجم التفاعل التقريبي |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | | | | | | | |
| 2 | | | | | | | |
| 3 | | | | | | | |
| 4 | | | | | | | |
| 5 | | | | | | | |

**كيف تحسب «حجم التفاعل» ببساطة**: آخر 10 منشورات ← اجمع الإعجابات والتعليقات ← اقسم على 10. رقم واحد يكفي للمقارنة (ليس إحصاءً رسمياً).

### مثال مغربي: قراءة الجدول

:: مثال
- **مثال افتراضي للتوضيح**: نادية تريد بيع «ساشي أكياس توصيل مقوّاة» للمطاعم الصغيرة.
- المنافس 1: مورد معروف، 0.40 درهم للساشي، الحد الأدنى 500، توصيل 48 ساعة، تعليقات: «الجودة مزيانة ولكن الحد الأدنى كبير».
- المنافس 2: محل محلي، 0.55 درهم، يبيع من 50، تعليقات: «كيلقاو في دُنيا واحنا».
- المنافس 3: بيع أونلاين، 0.45 درهم، توصيل مدفوع، تعليقات: «بانت طويلة التوصيل».
- القراءة: الفرصة ليست في «أن أكون أرخص من الجميع» (0.35 = سأخسر)، بل في: **حد أدنى 50 + توصيل في نفس اليوم داخل حي محدد**. نادراً ما يغطي المنافسون الثلاثة هذه الزاوية.
::end

### كيف تستفيد من المعلومات؟

- **الثمن**: لا تنزل تحت سقف تكاليفك أبداً لمواجهة منافس. عوّض بالسرعة، التغليف، الضمان، التوصيل المجاني داخل الحي.
- **الضعف المكرر في التعليقات**: هو نص إعلانك. إن كتب 4 زبائن «التوصيل كيطول»، اكتب في أول منشور: «التوصيل في نفس اليوم داخل ....».
- **القوة**: احترمها؛ لا تعلن حرباً لا تملك تكلفتها.

### ماذا لا تسجل؟ (أخطاء شائعة في الدراسة)

- لا تسجل أرقام «المتابعين» فقط — المتابع مشتري ما لا.
- لا تسجل مورداً كمنافساً: إن كنت ستشتري من نفس السوق، فأنت تقف في صف واحد معه في البداية.
- لا تسجل أكثر من 5–7 منافسين للمنتج الواحد في الاختبار الأول. ت enough المقارنة.

### تمرين

:: تمرين
- املأ جدول المنافسين بخمسة منافسين حقيقيين (روابط أو أسماء واضحة).
- اكتب فقرة واحدة: «الفرصة التي رأيتها هي ......... لأن .........».
- اكتب جملة واحدة تُثبت ضعف المنافسين لزبونك: «الزبون دابا كيتظلم من .........».
::end

### خطأ شائع

:: خطأ
- **«ما كايناش منافسة، ما لقيتش حتى واحد»**.
- أما الفكرة بلا منافسين فغالباً بلا زبائن، أو أنك بحثت بكلمة خاطئة.
- **الحل**: بدّل كلمات البحث (عربية/دارجة/فرنسية)، وابحث في المدينة المجاورة، وابحث في Marketplace أولاً.
::end

### خلاصة الفصل

:: خلاصة
- 5 منافسين × 7 أسطر = دراسة كافية للاختبار الأول.
- ضعف المنافس في التعليقات = مادة إعلانك.
- الفرصة في الفجوة (سرعة/حد أدنى/ضمان)، لا في السعر الأرخص.
::end

## الفصل 10: هل يوجد طلب؟ — سبع طرق مجانية لمعرفة ذلك قبل الشراء

### ماذا ستتعلم

- طرق مجانية (أو بكلفة تقرير صفر) لاكتشاف الطلب.
- الفرق بين الإعجاب والطلب، وبين الاستفسار والطلب المدفوع.
- عرض «ما قبل الشراء» كأسرع اختبار.

### الشرح: الطلب بأرقام، لا بمشاعر

**الطريقة 1 — «لوح الأسعار»**: انشر منشوراً واحداً بصورة واضحة وثمن واضح وطريقة طلب واضحة. بعد 72 ساعة سجّل: المشاهدات، الإعجابات، الرسائل، «واش الرابط؟»، «شحال التوصيل؟».
- الإعجاب = إعجاب.
- سؤال الثمن = اهتمام.
- سؤال المقاس/التوفر/الشحن = نية شراء عالية.
- تحويل بنكي/دفع عند الاستلام = طلب. **فقط الأخير يُحسب في «الطلب».**

**الطريقة 2 — قائمة انتظار (ما قبل الشراء)**: «المنتج غادي يجي الأسبوع الجاي، خاصني نعرف شكون باغي باش نحسب الكمية. سيب ليك رقمك وسنسقلك أول ما يوصل». إن كتب 10 أرقام، فالطلب شبه إثبات. إن كتب 0، اكتشفت ذلك قبل أن تدفع.

**الطريقة 3 — السوق المفتوح (Marketplace)**: ضع المنتج بسعر حقيقي. Marketplace يعطيك تفاعل قياسي: المشاهدات والرسائل أسبوعياً. لا حاجة لإعلان مدفوع.

**الطريقة 4 — مجموعات الحي/المدينة**: انشر في مجموعات البيع المحلية. قاعدة: اقرأ قوانين المجموعة، وانشر مرة واحدة جيدة بدل 5 مرات رديئة.

**الطريقة 5 — مقارنة «ما يُشترى فعلاً”**: من يباع 3 مرات أسبوعياً بالسعر ذاته = طلب مستمر. افتح إعلانات نشطة وانظر تاريخ آخر عملية إن ظهر، أو اسأله صراحة: «واش كيجيوكم طلبات كل أسبوع؟».

**الطريقة 6 — السؤال المباشر (5+5)**: اسأل 5 أشخاص في زبونك + 5 زبائن في السوق: «إذا كان X بـY، واش تشتريه أنت/تصيفط لصاحبك؟» — لا تقبل «إيه زوين»، اقبل «واش تخلص دابا؟».

**الطريقة 7 — الإعلان التجريبي الصغير**: 20–50 درهماً إعلان لمنشور واحد لمدة 48–72 ساعة، هدفه الردود لا المبيعات. إن كان «تكلفة الرد» (المبلغ ÷ عدد الردود) مقبولاً، فالإلكياءم بسيط. إن كان الردود صفر مع تفاعل كافٍ، فالمشكل في العرض أو الثمن لا في الطلب.

### مثال أرقامي: قراءة نتائج الاختبار

:: مثال
- **مثال افتراضي للتوضيح**: أنس نشر إعلان إكسسوارات بـ30 درهماً ميزانية.
- النتيجة: 4,200 مشاهدة، 38 إعجاباً، 9 رسائل، 4 أسئلة توصيل، 3 طلبات، طلب واحد مؤكَّد، صفر تسليم (الزبون تراجع).
- القراءة: الطلب موجود لكن المسار فيه تسريب: 9 رسائل ← 3 طلبات = تحويل 33% (ضعيف نسبياً)، والتأكيد ضعيف. قبل أن يُلوم أنس المنتج، يُصلح شيئين: سرعة الرد (الزبون يستنى أقل من دقيقة) ونص التأكيد (الجزء 12). لو بيعت الـ3، كان الرصيد الإجمالي جيداً.
::end

### عرض «ما قبل الشراء» بالتفصيل (خطوات)

1. صور فنية مقبولة (خلفية بيضاء + صورة استخدام).
2. منشور فيه: المشكلة، المنتج، الثمن، الثمن م inclus التوصيل، «الدفع عند الاستلام»، «الكمية محدودة بـ20» (إن كان صحيحاً فعلاً — لا تكذب بالعدد).
3. رد فوري على الرسائل بنسختين: سؤال الثمن، وسؤال التوفر/التوصيل.
4. بعد 72 ساعة: احسب الأرقام في جدول واحد، ثم قرار: اشترِ / عدّل الثمن أو العرض / غيّر المنتج.

### جدول قياس ما قبل الشراء

| المؤشر | قراءة قوية | قراءة ضعيفة | الإجراء |
| --- | --- | --- | --- |
| رسالة «شحال الثمن» | كثرة | قلّة | أصلح الصورة/الوصول أول |
| نسبة الرسائل ÷ الإعجابات | 10%+ | أقل من 3% | أعد كتابة الوصف |
| نسبة الطلب ÷ الرسائل | 30%+ | أقل من 10% | مشكل ثمن أو ثقة |
| نسبة التأكيد ÷ الطلب | 60%+ | أقل من 40% | أصلح التأكيد والتوصيل |

(نسب إرشادية لأول تجربة، تُقارن نتائجك بنفسك عبر الاختبارات — ليست معياراً عالمياً.)

### تمرين

:: تمرين
- اختر طريقتين من الطرق السبع المناسبتين لزبونك.
- نفّذ «ما قبل الشراء» واكتب جدول النتائج بعد 72 ساعة.
- اتخذ قراراً واحداً مكتوباً: اشتري / عدّل / غيّر — مع سبب من الأرقام.
::end

### خطأ شائع

:: خطأ
- **«100 إعجاب = 100 زبون محتمل»**.
- فرق كبير بين الإعجاب والطلب المدفوع. التقييم الوحيد الذي يُحسم به: من دفع أو أكد طلباً محدداً.
- **الحل**: عدّ في دفترك عموداً واحداً: «طلبات مؤكدة». هو ملكك.
::end

### خلاصة الفصل

:: خلاصة
- سبع طرق مجانية، وأقواها: ما قبل الشراء + Marketplace.
- الطلب = تأكيد أو دفع، لا إعجاب.
- جدول المؤشرات يحسم: اشترِ، عدّل، أو غيّر.
::end

## الفصل 11: قراءة السوق المغربي — كيف تفكر وأنت في المغرب تحديداً

### ماذا ستتعلم

- خصوصيات السوق المغربي الصغير: الثقة، الدفع عند الاستلام، المدن.
- كيف تستعمل الدارجة والمحلية دون أن تخاطب الجميع.
- أخطاء «نقل النسخة الأجنبية» إلى المغرب.

### الشرح: خمس خصوصيات تحكم اختبارك

**1. الثقة قبل المنتج.**
الزبون المغربي أونلاين يخاف من ثلاث: «يمشي الفلوس وما يوصلني والو»، «المنتج ما كيشبهش للصورة»، «يلقا منتوج قديم». كل عنصر في عرضك يجب أن يعالج واحدة من هذه الثلاث: صور حقيقية، فيديو قصير، تقييمات زبائن (لو وُجدت)، و«الدفع عند الاستلام».

**2. الدفع عند الاستلام (COD) هو الافتراضي في كثير من القطاعات.**
هذا يحول المخاطرة من الزبون إليك. لذا: التأكيد قبل الإرسال (الجزء 12) ليس خياراً، هو المنظومة كلها.

**3. التوصيل جزء من المنتج.**
شركة التوصيل وسعرها ووقتها ومدى تغطيتها لمدينتك: هذا يُحسب في الثمن من اليوم الأول. خدمة «يوصل في نفس اليوم» داخل حي واحد = ميزة تنافسية حقيقية.

**4. المدن ليست سوقاً واحداً.**
ما يبيع في الدار البيضاء قد يموت في إيموزار. ابدأ بمدينتك أو مدينتين متجاورتين. التوسع جغرافياً آخر ما يجي (الجزء 16).

**5. الموسمية عنيفة.**
رمضان، عيد الأضحى، عودة المدارس، صيفاً: من يبيع في الموسم يجب أن يعرف أن الموسم ينتهي. منتج موسمي بدون خطة «ما بعد الموسم» = مخزون ميت.

:: مثال
- **سيناريو تطبيقي**: شاب في طنجة يريد بيع «مظلة عصرية» بنسخة إيطالية رآها في تيك توك. في طنجة، مظلة قد تكون غير عملية لرياح الساحل، والزبون يقارن بـ«مظلة ديال الطونوبيل ب 50 درهم». النسخة الأجنبية تفشل في التفاصيل المحلية. البديل: مظلة قوية للسيارة/للشمس بضمان استبدال 7 أيام، مصورة على شاطئ طنجة، بتوصيل داخل طنجة. الفرق: نفس الفكرة، تكييف محلي.
::end

### الدارجة في العرض: متى تكتب بها؟

| النص | الأنسب |
| --- | --- |
| وصف منتج قصير في Marketplace | دارجة مبسطة |
| رسالة تأكيد طلب | دارجة واضحة |
| صفحة «من نحن»/الضمان | لغة أوضح قليلاً |
| عرض لشركة/مؤسسة | لغة فصحى مبسطة |

القاعدة: **اكتب كما يتحدث زبونك، وتحدثه حيث يتصفح.**

### أخطاء «النسخة الأجنبية»

- منتجات لا تناسب الحرارة/القياسات/العادات المحلية.
- أسعار محوّلة بحتة بلا مراعاة قوة الشراء (قارن دائماً بأسعار ما يُدفع فعلاً في سوقك، لا بأسعار أوروبا).
- نماذج توصيل لا توجد محلياً (نفس اليوم، توصيل لبيت، دفع عند الاستلام).
- إعلانات بصور غير مألوفة (زبون مغربي بخلفية أوروبية = إحساس «مستورد» قد يرفع الشك لا الثقة).

### تمرين

:: تمرين
- اكتب 3 خصوصيات محلية تنطبق على منتجك تحديداً (مدينة، موسم، عادة).
- اكتب كيف يعالج عرضك «الخوف الثلاثي»: صورة ......... / فيديو ......... / دفع ......... / ضمان .....
::end

### خطأ شائع

:: خطأ
- **«غادي نبيع لكل المغرب من أول يوم عبر الشحن»**.
- الشحن الأول يضاعف المشاكل: تكلفة، زمن، رفض، مرتجع.
- **الحل**: اختبر مدينتك (أو حيّك) أولاً بالتوصيل المباشر، ثم أضف الشحن الوطني بعد ثبوت الطلب وحسابك للتكلفة.
::end

### خلاصة الفصل

:: خلاصة
- الثقة + COD + التوصيل = عصب السوق المغربي أونلاين.
- ابدأ بمدينتك، واحترم الموسمية.
- جهّز عرضك بالدارجة أين يتصفح زبونك.
::end

::end
