# كتاب: مشروعي الأول فالمغرب

كتاب ورقي عملي (~324 صفحة A5) لصاحب المشروع المغربي المبتدئ الذي يملك بين 2,000 و10,000 درهم.

## الملف الجاهز

- `output/meshrooi-awal-f-alma.pdf` — نسخة PDF جاهزة للقراءة والطباعة (A5، هوامش للتجليد).

## بنية المشروع

| المسار | الدور |
| --- | --- |
| `engine.py` | محرك التحويل: نص مبسّط (mdown) → PDF عربي RTL بخطي Amiri وCairo |
| `build.py` | يبني الكتاب كاملاً من `content/*.md` (مع مرورين لضبط أرقام الفهرس) |
| `content/` | نص الكتاب (22 ملفاً بترتيب أجزائه الـ18) |
| `fonts/` | خطوط Amiri وCairo (مرخّصة OFL) |
| `output/` | ناتج البناء |

## إعادة البناء

```bash
# يتطلب: python3 مع حزم: fpdf2, uharfbuzz
python build.py
```

## قواعد المحتوى المطبَّقة

- كل قصة حقيقية لها **مصدر منشور** مذكور، والأرقام كما وردت في المصدر.
- حيث لا يوجد مصدر لرأس المال: «رأس المال الأولي غير موثق في المصدر المتاح».
- ثلاثة تصنيفات لا تختلط: **[تجربة حقيقية موثقة]** / **[مثال افتراضي للتوضيح]** / **[سيناريو تطبيقي]**.
- لا وعود بالربح ولا مشاريع «مضمونة»؛ الاختبار بالأرقام والحسابات لكل حالة.
